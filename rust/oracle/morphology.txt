# Java Audiveris 5.11 (JDK 25) grayscale morphology, from
# oracle/java/MorphoProbe.java.
#
# A unit oracle rather than an end-to-end one. oracle/beams-chula.txt grades the
# closing only through the beams it eventually produces, because Audiveris
# caches the closed buffer nowhere; that makes a wrong structuring element and a
# wrong beam recogniser look alike. These records call MorphoProcessor.close
# directly, so each layer answers for itself.
#
#   se     <radius> <width> <height> <area> <cells>
#   semask <row> <picture>        -- the mask, as characters
#   sevect <i> <dy> <dx> <value> <distance>
#   synthsrc <buffer> <w> <h> <digest>   -- the generated input, before closing
#   synth  <buffer> <w> <h> <radius> <digest>
#   synthpix.<buffer>.<radius> <row> <hex>   -- every pixel, for the small pair
#   sheet  <file>#<sheet> <w> <h> <digest>   -- the NO_STAFF buffer closed below
#   radius beam <b> smallBeam <s> used <u> diameter <d> radius <r>
#   closed <radius> <digest>      -- close() over that NO_STAFF buffer
#
# The last four records are what BEAMS feeds the closing rather than what
# morphology needs -- stem-run removal, median, gaussian, and then the closing
# of all three -- and are pinned here so the step around this one already has
# its gate.
#
# The two generated buffers come from formulas, not fixtures, so a port can
# rebuild them: `noise` is a Java int LCG (state = state * 1103515245 + 12345,
# byte = (state >>> 16) & 0xff), and `shapes` is white with bars and a blob in
# it. See the probe.
#

#   unset JAVA_TOOL_OPTIONS
#   JAVA_HOME=/path/to/jdk25/Contents/Home ./gradlew --no-daemon -q \
#     -I rust/oracle/java/staff-impacts.init.gradle :app:morphoProbe \
#     -PmorphoTargets="data/examples/chula.png:1"
